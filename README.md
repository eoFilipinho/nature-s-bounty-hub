# Nature's Bounty Hub

preciso que você crie um layout de um site para venda de produtos naturais, nele vai ter uma aba de inicio, que leva para a primeira página como os produtos destaques, vai ter a aba de produtos, que nela vão ter todos os produtos da loja, uma aba de Cereais, outra aba de tempeiros, outra aba de vitaminas, aba de suplementação,a aba de chás e por último a aba de grãos e sementes. Todas essas abas vão ficar alinhadas na horizontal que quando clicar em cada nome de vai ser levada para a aba desse produto, lembrando que será no cabeçalho isso, tendo que deixar um espaço do topo para a logo da loja, a barra de perquisa para procurar os produtos, o carrinho de compras no canto superior direito do cabeçalho com o número de itens dentro dele.
